# Non-programming Assignment
## Naming Convention
### Class 
- Class names should be nouns, using mixed case with the first letter of each word capitalized (PascalCase).
- The names should be simple and descriptive.
- Use whole words and avoid acronyms and abbreviations, unless widely used.
- eg. class Raster; class ImageSprite; class HelloWorld;

### Interfaces
- Interface names follow the same naming convention as class names (mixed case with the first letter capitalized).
- eg. interface RasterDelegate; interface Storing;

### Methods
- Methods should be named using verbs in mixed case: the initial letter must be lowercase, while the first letter of each internal word should be capitalized.
- eg. run(); runFast(); getBackground();

### Variables
- Variable names should be in mixed case with a lowercase first letter, with internal words starting with capital letters.
- Variable names should be short yet meaningful.
- Variable names should not start with underscore (_) or dollar sign ($) characters, even though both are allowed.
- eg. i; c; myWidth;

### Constants
- Class constants should be written in all uppercase letters with words separated by underscores (_).
- eg. MIN_WIDTH = 4; MAX_WIDTH = 999; GET_THE_CPU = 1;
